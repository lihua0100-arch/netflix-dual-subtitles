# Netflix 中英悬浮双字幕

[一键安装脚本](https://raw.githubusercontent.com/lihua0100-arch/netflix-dual-subtitles/main/netflix-dual-subtitles.user.js)

需要 Chrome 等浏览器及支持用户脚本的扩展（如 Tampermonkey）。安装后刷新 Netflix 播放页；在“中 / EN”面板选择中文来源。优先使用官方中文，若使用百度翻译，需自行开通百度通用文本翻译 API，并在面板填写 APP ID 与密钥。旧版安装用户请检查是否存在重复启用的脚本。

百度翻译会接收需要翻译的英文字幕；凭据保存在浏览器的 Netflix 站点本地存储中。请勿分享密钥。服务配额及费用以百度平台为准。

## 更新

脚本提供固定的更新和下载地址；脚本管理器需开启自动更新。维护者发布更新时必须递增 `@version` 并更新同路径脚本。更新检查的频率和安装方式取决于用户的脚本管理器设置。
