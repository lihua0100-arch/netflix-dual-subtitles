# Netflix 中英悬浮双字幕

[一键安装脚本](https://raw.githubusercontent.com/lihua0100-arch/netflix-dual-subtitles/main/netflix-dual-subtitles.user.js)

需要浏览器和用户脚本扩展（如 Tampermonkey）。安装后刷新 Netflix 播放页，在“中 / EN”面板选择中文来源。可以优先使用官方中文字幕；没有时可使用 MyMemory 免密钥机器翻译。字幕会发送给该服务；匿名免费额度有限，超额或服务不可用时可改用官方字幕或导入本地字幕。翻译质量可能有误。

旧版安装用户请检查是否存在重复启用的脚本。自动更新需在脚本管理器中开启；发布新版本时维护者须递增 `@version`，并更新相同路径的脚本。
